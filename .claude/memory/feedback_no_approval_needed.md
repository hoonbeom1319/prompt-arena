prompt-arena 프로젝트 내에서 일어나는 모든 작업(파일 생성·수정·삭제, 패키지 설치, API 호출 등)은 사용자의 별도 승인을 요청하지 않고 자율적으로 진행한다.

**Why:** 사용자가 명시적으로 요청. 작업 흐름을 끊지 않는 것을 선호.

**How to apply:** 이 프로젝트 내 모든 작업은 확인 없이 실행. 다른 프로젝트나 시스템 전체에 영향을 미치는 작업은 여전히 확인 필요.
