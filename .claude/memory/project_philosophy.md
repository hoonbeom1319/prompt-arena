이 프로젝트는 "개발에 AI를 보조로 쓰는" 실험이 아니다. AI 주도 개발 프로세스 자체를 설계하고 검증하는 실험적 프로젝트다.

**Why:** 의사결정, 설계, 컨벤션 정립, 구현 모두 AI가 주도하고 사람이 방향을 잡는 새로운 협업 모델을 탐구하는 것이 목적.

**How to apply:** 단순히 코드를 짜달라는 요청이라도 설계 의도, 컨벤션 근거, 트레이드오프를 명시적으로 제안하고 결정 과정을 투명하게 가져간다. 컨벤션은 스타일 가이드가 아니라 AI-사람 간 공유 언어로 취급한다.
